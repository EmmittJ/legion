# PRD: Project Legion

> **Tagline:** "for we are many."  
> **Architecture:** Hybrid Sentient/Deterministic Orchestration  
> **Foundational Engine:** Beads

## 1. Vision & Executive Summary

| Entity   | Category | Technical Definition                                                  |
| -------- | -------- | --------------------------------------------------------------------- |
| Grimoire | State    | The persistent Beads ledger (Dolt/Git) tracking all intent.           |
| Archon   | Control  | The K8s Controller that reconciles Grimoire with the Cluster.         |
| Vessel   | Compute  | An ephemeral K8s Pod hosting a specific Identity.                     |
| Molecule | Task     | A persistent Beads unit representing a specific goal.                 |
| Wisp     | Trace    | The ephemeral execution record (LLM turn/CLI exit) within a Molecule. |
| Rite     | Workflow | A templated sequence of bonded Molecules (e.g., the Bugfix Rite).     |

## 2. Hybrid Workforce (Identities)

Legion classifies labor into two distinct Vessel types to ensure reliability and cost-efficiency.

### 2.1. Sentient Vessels (LLM-Driven)

- **Hierophant (Architect):** Performs Expansion. Analyzes high-level input and seeds Grimoire with a Molecule graph.
- **Wraith (Worker):** Performs Manifestation. Writes code, documentation, or refactors within a specific Molecule. Also performs Peer Review of other Wraiths' output against the Pact (System Prompt).

### 2.2. Deterministic Vessels (Code-Driven)

- **Gauntlet (CI/Test):** Executes binary verification (Pytest, Linting, Builds).
- **Alchemist (Merge/Deploy):** Handles the final convergence of Shadow Branches into the Material Plane (main).

## 3. Technical Requirements

### 3.1. Archon Reconciliation Loop

- Archon must poll Grimoire for Molecules in a `READY` state (all dependencies/bonds satisfied).
- Archon must manifest these as Kubernetes Jobs.
- Archon must update Molecule status in Grimoire based on Vessel exit codes.

### 3.2. Forge (Git) Isolation

- Every active Molecule must operate on a unique Shadow Branch.
- Vessels must mount the repository via a Git Worktree to allow for simultaneous, conflict-free manifestation across the Many.

### 3.3. Immutable History

- Every Wisp (trace) generated by a Vessel must be inscribed into Grimoire.
- The system must support Resurrection: if a Vessel/Node fails, Archon restarts the Job using the last state in Grimoire.

## 4. System Architecture & Flow

1. **Invocation:** Summoner runs `lg invoke "Feature X"`.
2. **Expansion:** Archon summons Hierophant to define the Molecules and Bonds.
3. **Pulse:** Archon identifies ready Molecules and manifests Wraiths and Gauntlets in parallel.
4. **Trace:** Each Vessel records its progress as Wisps in the Beads ledger.
5. **Convergence:** Upon Wraith peer review approval and Gauntlet success, Alchemist merges the work.

## 5. Design Principles: "We are many"

- **Horizontal over Vertical:** Instead of one large agent, manifest fifty specialized Vessels.
- **Deterministic over Sentient:** Use real code (Gauntlet) to verify AI output wherever possible.
- **Ledger over Memory:** Agents do not "remember" sessions; they read Grimoire.

## 6. Next Steps: First Manifestation

To bring Legion to life, the following artifacts must be forged:

- **Archon Daemon:** The Python-based K8s reconciliation script.
- **Vessel Base Image:** A Docker image containing `git`, `beads-cli`, and the agent runtimes.
- **Hierophant Prompt:** The system logic for breaking intent into Molecules.
